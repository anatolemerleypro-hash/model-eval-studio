# Contributing

Thanks for helping improve Model Eval Studio.

1. Open an issue describing the change or bug.
2. Create a focused branch and include tests.
3. Run `ruff check .` and `PYTHONPATH=src python -m unittest discover -s tests -v` locally.
4. Submit a pull request explaining the user-visible impact.

Please keep evaluation rules transparent and avoid committing prompts that contain personal or confidential data.
